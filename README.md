# InAndOut

**Smarter logistics. Seamless movement.**

InAndOut is a multi-tenant B2B SaaS logistics platform designed to connect transport companies and terminals, streamline transport bookings, and simplify container handling and gate operations.

## Project Status

Under active development.

## Planned Features

- Role-based authentication and authorization
- Transport company and terminal management
- Fleet and driver management
- Transport booking and scheduling
- Container and yard management
- Truck check-in and check-out
- Operational dashboards and notifications
- Customer registration and approval
- Interactive public demo

## Technology Stack

| Category | Technology |
|---|---|
| Frontend | React, TypeScript, Vite |
| Backend | Node.js, Express, TypeScript |
| Database | MongoDB, Mongoose |
| Testing | Vitest, Supertest, Playwright |
| Real-time communication | Socket.IO |
| Containerization | Docker, Docker Compose |
| CI/CD | GitHub Actions |
| Reverse proxy | Nginx |
| Hosting | Self-hosted VPS |

## Architecture

The application follows a modular, layered architecture using object-oriented programming, SOLID principles, dependency injection, and separation of concerns.
